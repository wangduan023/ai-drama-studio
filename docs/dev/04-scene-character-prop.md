## 后台队列生成机制

### 任务提交流程

```
用户点击"生成场景图/角色图/道具图"
        │
        ▼
AI 生成提示词 → 弹出确认弹窗
        │
        ▼
用户确认/编辑提示词
        │
        ▼
任务提交到后端队列（获取任务 ID）
        │
        ▼
用户可关闭页面/离开
        │
        ▼
后端按优先级处理队列
        │
        ▼
生成完成 → 推送通知/页面展示结果
```

### 任务优先级规则

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| **高** | 用户当前页面正在等待 | 用户未关闭页面，实时显示进度 |
| **中** | 用户已离开页面但任务在 10 分钟内 | 后台处理，完成后发送通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 任务状态标识

| 状态 | 标识 | 说明 |
|------|------|------|
| **排队中** | ⏳ 排队中 (第 N 位) | 任务在队列中的位置 |
| **生成中** | 🔄 生成中...xx% | AI 正在处理 |
| **已完成** | ✓ 完成 | 生成成功，可预览 |
| **失败** | ✗ 失败 | 可点击重新尝试 |

### 通知机制

- **页面内通知**：用户未离开时，右上角弹出完成通知
- **站内信**：生成完成后添加到消息中心
- **结果展示**：用户返回页面时，自动展示已完成的生成结果
