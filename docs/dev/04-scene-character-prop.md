**页面路径:** `http://localhost:3333/projects/{projectId}/workflow/assets`

## 整体流程

```
剧本内容 ──→ LLM 分析 ──┬──→ 场景提取 ──→ 场景列表（可编辑）
            │           │
            ├──→ 角色提取 ──→ 角色列表（可编辑）
            │           │
            └──→ 道具提取 ──→ 道具列表（可编辑）
```

## 后台队列生成机制

### 任务优先级规则

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| **高** | 用户当前页面正在等待 | 用户未关闭页面，实时显示进度 |
| **中** | 用户已离开页面但任务在 10 分钟内 | 后台处理，完成后发送通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 任务状态标识

| 状态 | 标识 | 说明 |
|------|------|------|
| **排队中** | ⏳ 排队中 (第 N 位) | 任务在队列中的位置 |
| **生成中** | 🔄 生成中...xx% | AI 正在处理 |
| **已完成** | ✓ 完成 | 生成成功，可预览 |
| **失败** | ✗ 失败 | 可点击重新尝试 |
