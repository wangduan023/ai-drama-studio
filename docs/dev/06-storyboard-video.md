## 三种视频生成模式

### 1. 图生视频模式

| 输入 | 原理 | 适用场景 |
|------|------|---------|
| 单张分镜图 | 基于单图生成动态视频，可控制镜头运动 | 静态场景、简单动作 |

**镜头运动选项：**

| 运动类型 | 视觉效果 | 适用场景 |
|---------|---------|---------|
| **无** | 静态画面，无运动 | 特写、定格画面 |
| **固定机位** | 画面静止，主体可动 | 对话场景、静态展示 |
| **跟拍** | 镜头跟随主体移动 | 行走、奔跑场景 |
| **环绕** | 镜头围绕主体旋转 | 展示人物、强调主体 |
| **变焦拉近** | 镜头向前推进，特写主体 | 情感强调、细节展示 |
| **变焦拉远** | 镜头向后拉远，展示环境 | 开场、转场 |
| **镜头左摇** | 镜头向左平移 | 展示左侧环境、跟随移动 |
| **镜头右摇** | 镜头向右平移 | 展示右侧环境、跟随移动 |

### 2. 多参生视频模式

| 输入 | 原理 | 适用场景 |
|------|------|---------|
| 多张参考图/参数 | 基于多张图生成复杂动画 | 角色动作、复杂场景 |

## 生成流程

```
1. 选择要生成视频的分镜
      │
      ▼
2. 确认分镜图已设置（自动带入）
      │
      ▼
3. 选择视频生成模式
      │
      ├─→ 图生视频：选择镜头运动
      │
      ├─→ 多参生视频：上传多张参考图
      │
      └─→ 首尾帧视频：上传首帧+尾帧
      │
      ▼
4. （可选）选择特殊拍摄手法
      │
      ▼
5. 补充画面动作描述
      │
      ▼
6. 设置视频参数（模型/时长/数量/画质）
      │
      ▼
7. 点击"开始生视频"（消耗15🪙）
      │
      ▼
8. 等待生成完成，预览视频效果
      │
      ├─→ 满意：设为分镜视频
      │
      └─→ 不满意：调整参数重新生成
```

## 后台队列生成机制

### 任务提交流程

```
用户点击"开始生视频"
        │
        ▼
AI 生成提示词 → 弹出确认弹窗
        │
        ▼
用户确认/编辑提示词
        │
        ▼
任务提交到后端队列（获取任务 ID）
        │
        ▼
用户可关闭页面/离开
        │
        ▼
后端按优先级处理队列
        │
        ▼
生成完成 → 推送通知/页面展示结果
```

### 任务优先级规则

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| **高** | 用户当前页面正在等待 | 用户未关闭页面，实时显示进度 |
| **中** | 用户已离开页面但任务在 10 分钟内 | 后台处理，完成后发送通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 任务状态标识

| 状态 | 标识 | 说明 |
|------|------|------|
| **排队中** | ⏳ 排队中 (第 N 位) | 任务在队列中的位置 |
| **生成中** | 🔄 生成中...xx% | AI 正在处理 |
| **已完成** | ✓ 完成 | 生成成功，可预览 |
| **失败** | ✗ 失败 | 可点击重新尝试 |

### 通知机制

- **页面内通知**：用户未离开时，右上角弹出完成通知
- **站内信**：生成完成后添加到消息中心
- **结果展示**：用户返回页面时，自动展示已完成的生成结果
