│     ├─ 图生视频：单张分镜图+镜头运动→生成视频                                 │
│     ├─ 多参生视频：多张参考图→生成复杂动作视频                                │

## 核心特色

1. **全流程AI驱动**：从剧本到成片，AI自动完成分镜、画面、视频、配音
2. **可视化编辑**：时间轴编辑器，所见即所得
3. **角色一致性**：角色三视图确保不同分镜中人物形象统一
4. **灵活调整**：每个环节都支持人工干预和精细调整
5. **成本可控**：提供多种画质选择，满足不同预算需求
6. **后台队列处理**：AI 任务提交后可关闭页面，完成后通知用户
7. **提示词确认**：AI 生成提示词需用户确认后才开始执行

## 后台队列机制

### 任务提交流程

所有 AI 生成任务（场景图、角色图、道具图、分镜图、分镜视频、配音）均遵循以下流程：

```
用户触发 AI 生成
        │
        ▼
AI 生成提示词/参数
        │
        ▼
弹出确认弹窗（用户可编辑）
        │
        ▼
用户确认 → 提交后端队列
        │
        ▼
用户可关闭页面/离开
        │
        ▼
后端按优先级排队处理
        │
        ▼
生成完成 → 推送通知
        │
        ▼
用户返回页面查看结果
```

### 优先级规则

| 优先级 | 触发条件 | 处理方式 |
|--------|---------|---------|
| **高** | 用户当前页面等待 | 实时显示进度，优先处理 |
| **中** | 用户已离开（10 分钟内） | 后台处理，完成通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 通知方式

- **页面内通知**：右上角弹窗通知
- **站内信**：消息中心记录
- **结果展示**：返回页面自动展示完成结果

## 使用建议

1. **新手用户**：使用默认配置，跟随流程逐步操作
2. **专业用户**：在生成设置中调整参数，精细控制输出质量
3. **高效制作**：使用批量生成功能，快速完成大量分镜
4. **质量保证**：关键分镜使用九宫格模式，选择最佳构图
