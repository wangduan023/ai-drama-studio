## 时间轴轨道详解

| 轨道 | 内容 | 功能 | 操作 |
|------|------|------|------|
| **视频轨道** | 分镜缩略图序列 | 展示所有分镜画面 | 拖拽调整顺序、删除、替换 |
| **配音轨道** | 音频波形/状态图标 | 显示各分镜配音情况 | 调整音量、淡入淡出 |
| **字幕轨道** | 绿色时间块+台词 | 显示字幕出现时间和内容 | 调整时间、编辑文字 |
| **音乐轨道** | 橙色音频条 | 背景音乐 | 调整音量、裁剪、替换 |

## 当前播放状态

| 元素 | 说明 |
|------|------|
| **主画面** | 显示当前时间轴指针位置的帧画面 |
| **字幕叠加** | 当前时间对应的台词显示在画面底部 |
| **时间刻度** | 显示视频总时长（示例：00:15 - 00:58） |
| **播放头** | 绿色竖线，指示当前播放/预览位置 |

## 操作功能

| 按钮/功能 | 说明 |
|-----------|------|
| **更新视频到时间轴** | 如后续修改了分镜，点此更新到时间轴 |
| **导出视频** | 生成最终成片，支持选择分辨率/格式 |
| **播放/暂停** | 预览时间轴内容 |
| **拖拽分镜** | 调整分镜顺序 |
| **调整字幕时间** | 拖动绿色块边缘调整出现/消失时间 |

### 导出参数说明

| 参数 | 选项 | 说明 |
|------|------|------|
| **分辨率** | 720P / 1080P / 2K / 4K | 输出视频清晰度 |
| **格式** | MP4 / MOV | 视频文件格式 |
| **包含字幕** | 是/否 | 是否叠加字幕到视频 |
| **包含配音** | 是/否 | 是否包含配音音频 |
| **包含音乐** | 是/否 | 是否包含背景音乐 |

## 播放控制

| 控制 | 功能 |
|------|------|
| **播放/暂停** | 开始或暂停预览 |
| **快进/快退** | 10秒为单位跳转 |
| **进度条拖拽** | 跳转到指定时间点 |
| **音量控制** | 调整预览音量 |
| **全屏** | 全屏预览视频 |

## 快捷操作

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放/暂停 |
| `←` | 后退5秒 |
| `→` | 前进5秒 |
| `↑` | 音量增加 |
| `↓` | 音量减少 |
| `F` | 全屏切换 |

## 最终输出

导出完成后：
- 视频文件保存到本地
- 可选择分享到平台

## 完整流程总结

至此，`纳米漫剧流水线` 的完整七步操作流程已全部完成：

1. ✅ **全局设定** - 配置项目基础参数
2. ✅ **故事剧本** - 输入/导入剧本内容
3. ✅ **场景角色道具** - AI智能提取并生成视觉资产
4. ✅ **分镜脚本** - AI拆分为分镜并生成静态画面
5. ✅ **分镜视频** - 将静态分镜转换为动态视频
6. ✅ **配音对口型** - 添加配音并自动对口型
7. ✅ **视频预览** - 时间轴编辑并导出最终成片
