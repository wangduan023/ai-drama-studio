## 功能区域说明

| 区域 | 功能 | 说明 |
|------|------|------|
| **编辑工具栏** | 撤销/重做/复制/清空 | 标准文本编辑操作 |
| **导入按钮** | 导入剧本（单集） | 支持从文件导入（.txt/.docx/.pdf） |
| **历史版本** | 查看历史编辑记录 | 可回溯/对比/恢复历史版本 |
| **文本编辑区** | 富文本输入 | 支持粘贴、格式化输入 |
| **字符计数** | 0/10000 | 实时统计，建议2000字以内，最大10000字 |

## 交互规则

| 元素 | 交互 | 行为 |
|------|------|------|
| 撤销/重做 | 点击 | 历史操作回退/前进 |
| 复制 | 点击 | 复制当前全部文本到剪贴板 |
| 清空 | 点击 | 二次确认后清空编辑区 |
| 导入剧本 | 点击 | 打开文件选择器，支持批量导入 |
| 历史版本 | 点击 | 侧边展开历史版本列表 |
| 文本区 | 输入 | 实时保存草稿，显示字符计数 |
| 下一步 | 点击 | 文本非空时进入下一步 |

## 校验规则

- **必填**：剧本内容不能为空
- **建议字数**：2000字以内（获得最佳分镜效果）
- **最大限制**：10000字
- **格式支持**：导入时自动过滤特殊格式
