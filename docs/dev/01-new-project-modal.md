# 原型方案 - 步骤1：新建作品弹窗

## 界面结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  新建作品    仅需填写名称，即可新建作品（所有作品素材将自动保存至资产库）   X │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  作品名称(单集)* （适用于有连续剧情的作品）                                   │
│  ┌───────────────────────────────────────────────────────────┐             │
│  │ 请填写本集作品名称                                  0/25 │             │
│  └───────────────────────────────────────────────────────────┘             │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────┐             │
│  │                    作品创作，仅需4步                       │             │
│  │                                                           │             │
│  │   ①全局设定 → ②添加剧本(单集) → ③生成资产 → ④生成视频   │             │
│  └───────────────────────────────────────────────────────────┘             │
│                                                                             │
│                              [  取消  ]        [    确定新建    ]           │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 界面元素详解

| 区域 | 元素 | 说明 |
|------|------|------|
| **头部** | 标题"新建作品" | 弹窗主标题 |
| | 说明文字 | "仅需填写名称，即可新建作品（所有作品素材将自动保存至资产库）" |
| | 关闭按钮(X) | 点击关闭弹窗 |
| **输入区** | 标签"作品名称(单集)*" | 必填项标识 |
| | 补充说明 | "（适用于有连续剧情的作品）" |
| | 输入框 | 占位符："请填写本集作品名称" |
| | 字符计数 | "0/25"，实时显示输入字符数 |
| **流程说明** | 标题"作品创作，仅需4步" | 引导用户了解后续流程 |
| | 4步流程图 | ①全局设定 → ②添加剧本(单集) → ③生成资产 → ④生成视频 |
| **底部操作** | 取消按钮 | 关闭弹窗，不创建项目 |
| | 确定新建按钮 | 校验通过后创建项目 |

## 交互规则

| 元素 | 交互 | 状态/行为 |
|------|------|----------|
| 输入框 | 聚焦 | 边框高亮，可输入文字 |
| 输入框 | 输入 | 实时更新字符计数（0/25 → n/25） |
| 输入框 | 失焦校验 | 空值时显示红色提示"请输入作品名称" |
| 确定新建 | 点击（空值） | 显示校验错误提示，不关闭弹窗 |
| 确定新建 | 点击（有效） | 校验通过后创建项目，跳转至全局设定页面 |
| 取消/X | 点击 | 关闭弹窗，返回作品列表 |

## 校验规则

- **必填**：作品名称不能为空
- **长度限制**：1-25 字符
- **特殊字符**：不允许 `< > / \` 等特殊符号
- **重复校验**：同一用户下作品名称不能重复

## 4步流程说明

点击"确定新建"后将进入以下流程：

| 步骤 | 名称 | 说明 |
|------|------|------|
| **①** | 全局设定 | 配置画面比例、剧本类型、模型策略等 |
| **②** | 添加剧本(单集) | 输入或导入剧本内容 |
| **③** | 生成资产 | AI提取场景、角色、道具并生成视觉图 |
| **④** | 生成视频 | 生成分镜、视频、配音，最终导出成片 |

## 下一步流向

点击「确定新建」→ 校验通过 → 创建项目成功 → 进入 **步骤2：全局设定**
