## 自动配音功能

点击右上角「🔄 自动生成分镜配音」按钮：

- 根据分镜中的发言角色自动匹配音色
- 根据台词内容生成语音
- 自动对口型（与视频画面同步）

## 配音生成流程

```
1. 确认分镜视频已生成
      │
      ▼
2. 系统自动提取台词和角色
      │
      ▼
3. 为每个有台词的分镜分配音色
      │
      ├─→ 如角色已在角色设置中配置音色，自动使用
      │
      └─→ 如未配置，使用默认音色或提示用户选择
      │
      ▼
4. 生成配音音频
      │
      ▼
5. AI对口型（将音频与视频人物口型同步）
      │
      ▼
6. 合并音视频
      │
      ▼
7. 配音完成，可试听和调整
```

## 对口型技术说明

| 技术 | 效果 |
|------|------|
| **音频生成** | 根据台词和音色生成自然语音 |
| **口型同步** | AI分析音频，自动匹配人物口型动画 |
| **表情同步** | 根据语气调整人物表情 |
| **音视频合并** | 将配音与原视频画面合成 |

## 后台队列生成机制

### 任务提交流程

```
用户点击"自动生成分镜配音"或"生成配音"
        │
        ▼
AI 生成台词和角色分配 → 弹出确认弹窗
        │
        ▼
用户确认/编辑台词和配音参数
        │
        ▼
任务提交到后端队列（获取任务 ID）
        │
        ▼
用户可关闭页面/离开
        │
        ▼
后端按优先级处理队列
        │
        ▼
生成完成 → 推送通知/页面展示结果
```

### 任务优先级规则

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| **高** | 用户当前页面正在等待 | 用户未关闭页面，实时显示进度 |
| **中** | 用户已离开页面但任务在 10 分钟内 | 后台处理，完成后发送通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 任务状态标识

| 状态 | 标识 | 说明 |
|------|------|------|
| **排队中** | ⏳ 排队中 (第 N 位) | 任务在队列中的位置 |
| **生成中** | 🔄 生成中...xx% | AI 正在处理 |
| **已完成** | ✓ 完成 | 生成成功，可预览 |
| **失败** | ✗ 失败 | 可点击重新尝试 |

### 通知机制

- **页面内通知**：用户未离开时，右上角弹出完成通知
- **站内信**：生成完成后添加到消息中心
- **结果展示**：用户返回页面时，自动展示已完成的生成结果

## 特殊配音类型

| 类型 | 说明 |
|------|------|
| **对白** | 角色之间的对话，需发言角色 |
| **旁白** | 画外音解说，可选择音色 |
| **内心独白** | 角色内心想法，需发言角色 |
| **环境音** | 场景音效（掌声、风声等） |
