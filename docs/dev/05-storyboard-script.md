## 功能区域说明

| 区域 | 功能 | 说明 |
|------|------|------|
| **视图切换** | 列表/卡片 | 切换分镜展示方式（列表视图/卡片视图） |
| **进度显示** | 分镜完成进度：0/1 | 显示已完成分镜数/总分镜数 |
| **添加分镜** | + 添加分镜 | 手动添加新的分镜卡片 |
| **自动拆分** | 自动拆分镜脚本 | AI根据剧本自动拆分为多个分镜 |
| **自动生图** | 自动生分镜图 | 为所有分镜自动生成预览图 |

## 分镜卡片结构

每个分镜包含三个核心区域：

| 区域 | 内容 | 操作 |
|------|------|------|
| **分镜图** | 分镜预览图（初始为空） | 点击"编辑分镜"进入画图界面 |
| **参考图片** | 关联的场景/角色/道具图 | 自动引用已生成的资产 |
| **分镜脚本** | 分镜文字描述 | 点击编辑或自动生成 |

## 分镜卡片操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| **分镜视频** | 生成分镜视频 | 将该分镜转换为动态视频 |
| **配音对口型** | 添加配音 | 为分镜添加配音和口型同步 |
| **修改分镜脚本** | 编辑文字 | 修改分镜的文字描述内容 |
| **编辑分镜图** | 编辑画面 | 进入画布编辑分镜画面构图 |
| **复制分镜** | 复制当前分镜 | 创建该分镜的副本 |
| **删除分镜** | 删除分镜 | 移除该分镜（不可逆） |

### 镜头密度对比

| 模式 | 镜头数/千字 | 适用场景 | 特点 |
|------|------------|---------|------|
| **精简模式** | ~35个 | 快节奏短剧、信息流视频 | 重点突出、节奏紧凑、成本低 |
| **标准模式** | ~65个 | 常规剧情短剧 | 结构完整、节奏适中、推荐 |
| **细拆模式** | ~80个 | 精品短剧、电影感作品 | 细节丰富、画面感强、成本高 |

### 生图模型对比

| 模型 | 标签 | 特点 | 价格 |
|------|------|------|------|
| **纳米修图Pro** | 效果最好 | 画质最高、细节最精细 | 16🪙/张(4K) |
| **纳米修图2** | - | 画质、成本、速度全面均衡 | 14🪙/张(4K) |
| **即梦5.0lite** | 性价比最高 | 速度快、成本低、质量可接受 | 4🪙/张 |
| **可图omni** | - | 兼顾画质效率 | 2🪙/张 |

## 后台队列生成机制

### 任务提交流程

```
用户点击"开始生图"
        │
        ▼
AI 生成提示词 → 弹出确认弹窗
        │
        ▼
用户确认/编辑提示词
        │
        ▼
任务提交到后端队列（获取任务 ID）
        │
        ▼
用户可关闭页面/离开
        │
        ▼
后端按优先级处理队列
        │
        ▼
生成完成 → 推送通知/页面展示结果
```

### 任务优先级规则

| 优先级 | 触发条件 | 说明 |
|--------|---------|------|
| **高** | 用户当前页面正在等待 | 用户未关闭页面，实时显示进度 |
| **中** | 用户已离开页面但任务在 10 分钟内 | 后台处理，完成后发送通知 |
| **低** | 批量生成任务 | 系统空闲时处理 |

### 任务状态标识

| 状态 | 标识 | 说明 |
|------|------|------|
| **排队中** | ⏳ 排队中 (第 N 位) | 任务在队列中的位置 |
| **生成中** | 🔄 生成中...xx% | AI 正在处理 |
| **已完成** | ✓ 完成 | 生成成功，可预览 |
| **失败** | ✗ 失败 | 可点击重新尝试 |

### 通知机制

- **页面内通知**：用户未离开时，右上角弹出完成通知
- **站内信**：生成完成后添加到消息中心
- **结果展示**：用户返回页面时，自动展示已完成的生成结果
